# Task Manager (MVC Architecture)

CLI task manager application built following strict MVC pattern.

## System Architecture

* **Models (`models/`)**: Business objects, reports, and file persistence.
* **Views (`views/`)**: Console display and user input methods.
* **Controllers (`controllers/`)**: Application routing and workflows.
* **Main Script (`main.py`)**: Entry point launching application.

## Run Application

```bash
python main.py
